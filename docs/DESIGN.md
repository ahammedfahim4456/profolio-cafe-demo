# Design Specification

## Brand

Brew & Bean Café

## Style

Modern, premium and warm café aesthetic.

## Layout

Clean and responsive.

## Desktop

Full navigation and multi-column sections.

## Mobile

Responsive navigation and stacked content.

## Typography

Modern sans-serif fonts.

## Buttons

Rounded buttons with clear call-to-action text.

## Cards

Clean cards with consistent spacing.

## Animations

Subtle hover and transition effects.

## Responsive

Must work on:
- Desktop
- Tablet
- Mobile
